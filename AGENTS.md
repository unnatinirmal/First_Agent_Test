# Agent Instructions

## Commit Messages

- Heading must be less than 40 characters.
- Body lines must be less than 80 characters.
- Each body line must start with `- `.
- Prefer individual body lines over paragraphs.

## Git Workflow

- Agents may create commit messages for completed changes.
- Agents may stage and commit completed changes locally.
- Agents should leave pushing to the remote repository for the user.
- Agents should confirm the final commit hash after committing.
