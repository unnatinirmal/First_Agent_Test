# Browser Tetris

A small browser-based Tetris game you can run locally.

## Launch

Open `index.html` in your browser, or serve this folder with any local static server.

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Left / Right: move
- Up or X: rotate
- Down: soft drop
- Space: hard drop
- P: pause
